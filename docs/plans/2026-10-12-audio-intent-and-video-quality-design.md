# AIXCut 声音意图与成片质量设计

## 目标

让桌面 Plugin 在完整成片任务中先识别原始声音、AI 配音和背景音乐的意图，再按真实依赖执行，避免无条件生成配音或音乐；同时保留已经完成的字幕、转录和 Motion Graph 隔离规则。

## 现状与问题

- 完整成片 Skill 已有视觉、配音、字幕、音乐和导出顺序，但声音步骤仍容易被理解为必做步骤。
- `aixcut-voice` 说明了 render 与落轨的区别，却没有要求在生成前读取原始音频和用户的声音意图。
- 时间轴音频规则说明了音轨、音量和淡化，但没有定义“保留、替换、生成、禁止”的决策状态。
- 最新 AIXCut Agent 提示词要求不要凭推断增加音乐、字幕或生成素材；桌面 Plugin 需要把这个约束落实到具体 Skill 和契约测试。

## 设计

### 1. 声音意图闸门

完整成片开始时读取 Project、Timeline、音频轨、素材转录和已有 Voice 状态。把声音请求归类为：

| 状态 | 行为 |
| --- | --- |
| `preserve-original` | 保留已有原声，不创建新 AI 配音 |
| `generate-voice` | 用户明确要求新 AI 配音，进入 Voice 流程 |
| `replace-original` | 用户明确要求替换口播，只处理相关范围 |
| `add-music` | 用户明确要求背景音乐，单独加音乐轨并淡化 |
| `no-music` | 用户明确不需要音乐，禁止生成或添加 |
| `optional-music` | 用户只说“可选音乐”或没有提音乐，默认不添加；只有用户确认后才添加 |
| `needs-clarification` | 原声是否替换会改变成片且用户未说明时，只问一个推荐问题 |

已有正确口播时默认保护原声。用户只要求剪辑、字幕或画面结构时，不得因为使用完整成片 Skill 自动生成 AI 配音。

### 2. 依赖顺序与阶段条件

保留最新 AIXCut 的依赖顺序，但将声音阶段变为条件分支：

```text
读取素材与时间轴
  ↓
识别原声 / 配音 / 音乐意图
  ↓
视觉结构
  ↓
仅在 generate-voice 或 replace-original 时生成并落轨 AI 配音
  ↓
仅在有真实可用转录时生成口播字幕
  ↓
仅在 add-music 且用户已确认时添加背景音乐
  ↓
独立核对原声、配音、字幕、音乐和视觉标注
  ↓
导出
```

阶段汇报继续默认自动推进；只有关键选择、费用、覆盖风险或用户要求检查点时暂停。

### 3. 成片质量规则

- 字幕只包含真实说出的内容；转录未 `available` 时不得用文稿冒充。
- 原始口播、AI 配音和 BGM 必须在独立的声音角色/轨道中核对，禁止无意双重人声。
- BGM 只在被启用时添加，必须覆盖真实时长、设置淡入淡出并降低人声下音量。
- 食材标签、箭头、虚线圆圈和 Motion Graph 归入视觉标注，使用独立 `art-text` 或 Motion Graph 轨；不得写入字幕轨。
- 每次结构写入后立即读回受影响的 Timeline、Audio 或 Captions view。
- 完成汇报必须区分“结构检查通过”和“完整播放/试听已验证”。

## 测试设计

新增契约测试覆盖：

1. 完整成片 Skill 包含声音意图闸门、原声保护和条件化音乐/配音规则。
2. Voice Skill 要求生成前读取当前 Voice、Timeline 和音频状态，并明确不因完整成片请求自动生成。
3. Timeline Skill 保留音频轨道角色、淡化、原声保护和独立视觉标注规则。
4. 回归测试覆盖柠檬水提示词：已有口播时不自动新增 AI 配音；“可选背景音乐”默认不添加；标签/箭头/圆圈不进入字幕轨。

## 边界

- 只修改 `agent-plugin/shared/skills/`、对应契约测试和构建产物。
- 不修改 `aixcut` Agent Server、`aixcut-mcp-server`、MCP Tool Schema、Studio UI 或后端业务逻辑。
- 不改变工具字段和协议，只补充 Agent 使用规则和可验证的契约。
