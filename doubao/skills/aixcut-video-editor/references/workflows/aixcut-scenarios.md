# 五大核心剪辑场景工作流

当用户提出口播精剪、直播切片、电商信息流、TVC 品牌广告或矩阵批量生产需求时，按对应场景规划结构、节奏、视觉包装与验收标准，再配合 `aixcut-timeline-editing`、`aixcut-captions`、`aixcut-voice`、`aixcut-visual-effects` 与 `aixcut-export` 执行。

## 1. 口播精剪（Talking-Head）

- 详细步骤见[口播精剪](aixcut-talking-head.md)。
- 先读 `source_lines`，按语义单元而非单字删除口误、重复与拖沓停顿；保留自然呼吸与原意；补齐字幕并核验口型/声画同步。

## 2. 直播切片（Livestream Clips）

- **高光定位**：读取 `source_lines` 或源素材转写，围绕“单一核心卖点 / 强情绪反转 / 明确行动号召（CTA）”拆出独立高光片段，每条切片只打透一个主题。
- **开篇钩子**：前 3 秒直接切入最强冲突、结论、价格利益点或产品痛点演示，去掉冗长寒暄与等待上人片段。
- **节奏与字幕**：删掉直播间无效互动与长时间停顿；给核心利益点与价格信息配清晰大字字幕，注意避开平台上下左右 UI 遮挡区。
- **多条拆条**：需要拆出多条切片时，优先用 `aixcut_timeline(action="create")` 或 `duplicate` 为每条切片建立独立时间线，避免互相覆盖。

## 3. 电商信息流（E-Commerce Feed Ads）

- **黄金结构**：按“3 秒痛点/钩子 → 核心卖点演示（画面实拍优先） → 信任背书/对比 → 限时利益与 CTA”组织结构，默认竖屏 `9:16`（1080×1920）快节奏出片。
- **单条单一卖点**：一条信息流聚焦 1 个核心卖点或购买疑问；多卖点拆成矩阵版本分别投放，不堆砌文字。
- **克制花字与安全区**：同一画面最多 1 处视觉强调；价格/核心词可用重点样式，避免整句大红大黄花字遮挡主体（人脸、产品、操作区）。
- **事实与合规**：所有价格、参数、活动时间严格以用户提供资料为准；禁止出现极限词（如“全网第一”“100% 有效”“绝对”）或未授权承诺。

## 4. TVC 品牌广告（TVC Commercial）

- **节奏与画幅**：常见 15 秒 / 30 秒 / 60 秒，横屏 `16:9` 主版或按需同步竖屏适配版；按“品牌情绪引入 → 场景/产品质感展示 → 品牌主张（Slogan）→ 落版定格”推进。
- **视听统一**：镜头转场、调性、配乐情绪与旁白音色保持克制统一；音乐音量低于人声并做好淡入淡出（`fade_in_ms` / `fade_out_ms`），避免喧宾夺主。
- **素材与生成边界**：需要 AI 生成概念画面或配乐时，先向用户报价并获明确确认；生成画面不得冒充实拍或实测证据。

## 5. 矩阵批量生产（Matrix Batch Production）

- **做实质差异，拒绝无效微调**：先向用户确认矩阵差异表（不同开篇钩子、不同核心卖点切入、不同画幅 `9:16` / `16:9`、不同口播/字幕风格或 B-roll 组合），再按版本逐条创建独立时间线执行。
- **公共信息联动**：若活动价格、品牌名或必留声明变更，必须同步检查并更新所有关联版本时间线的字幕、文字与旁白，确保全矩阵口径一致。

## 6. 工程文件导出与未授权降级

- **多形态导出**：默认交付可编辑时间线；用户要求导出成片或工程文件时，走[导出工作流](aixcut-export.md)打开 Aixcut Studio 导出弹窗（支持导出视频、音频、动态图形、XML、Aixcut 工程与主流后期软件工程文件），或对云端就绪素材使用无头视频渲染。
- **未授权降级**：若豆包连接器尚未完成 Aixcut 授权而用户已给出明确场景诉求，先按对应场景交付一份结构化、可直接落地的剪辑方案（钩子、分镜、节奏、字幕/配乐与差异表），再提示用户在豆包完成连接器授权后直接落入时间线。
