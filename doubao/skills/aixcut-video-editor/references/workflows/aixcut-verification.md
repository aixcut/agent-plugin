# 成果验证

用结构、语义、视觉和音频证据验证 Aixcut 成果，只读，不修改时间线。

## 最短路径

1. 读取受影响视图，例如 `timeline`、`captions`、`speech`。
2. 调用 `aixcut_review` 做结构检查。
3. 用户需要视觉确认时捕获真实合成帧。
4. 报告已通过项和未检查项。

每个写入都需要与请求匹配的验证；工具返回 `applied` 本身不是最终结论。

## Review 范围

| view | 检查 |
| --- | --- |
| `project` | 项目结构、轨道与整体状态 |
| `timeline` | 片段顺序、时长、空隙与重叠 |
| `timeline` + `speech` 回读 | 语音脚本、实际配置与时间线放置 |
| `renderability` | 静态结构、源可用性和有效时长 |

画布超过 4K UHD 像素预算时返回 `CANVAS_HIGH_RESOLUTION` 警告；不要自动改画布，向用户说明影响。

## 证据边界

- 结构证据绑定同一 Project、Timeline 和整数 `revision`。
- 视觉证据使用真实合成帧，缩略图不能替代。
- 音频证据需要实际试听；宿主不能播放时标为 `unjudgeable`。
- 硬失败存在时不得交付；证据不足时说明缺口，不用模型自评替代。
